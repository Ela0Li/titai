# 题台 · titai

一个离线优先的安卓刷题与自查 App。知识点、问答、收藏、刷题四件事放在一个界面里，内容（学习包）与程序分离——**换主题不用换 App，换 App 不会丢内容**。

不联网、不登录、不要账号；进度全存在手机里。

## 下载安装

到 [Releases](https://github.com/Ela0Li/titai/releases) 下载最新的 `titai-x.y.z.apk`，在手机上打开安装（首次需允许「安装未知来源应用」）。

- 系统要求：**Android 8.0**（API 26）及以上，安装包约 120 KB
- 新版本直接覆盖安装，进度保留
- 没有 Play 商店版本，也不打算上

## 里面有什么

两个机器学习主题的学习包，串成一条学习路径：

| 学习包 | 模块 | 知识点 | 问答 |
|---|---|---|---|
| 机器学习数学基础 | 5 | 32 | 24 |
| 机器学习入门 · 从数据到上线 | 9 | 54 | 60 |

默认打开「机器学习入门」计划：**数学基础 → 机器学习入门**。想换主题就导入自己的包，见下一节。

## 怎么用

- **知识点**：按模块分区，每条带等级（P0/P1/P2）和一句「及格线」（说到什么程度算过）。点圆点记掌握度：未学 / 模糊 / 会 / 熟练，再点同一个点可以清掉。
- **问答**：问题在上、答案在下；答案按内容自由分段，可能带 1–3 级小标题和要点列表。答案里写 `$…$` 或 `$$…$$` 会渲染成公式。
- **收藏**：攒下想反复看的条目。
- **刷题**：按掌握度抽题，答完直接打点。
- **搜索**：随便输入。支持汉字、全拼、首字母（`jcs` → 交叉熵）、多词（空格分隔，全部命中才算），结果按相关度排序并高亮；问答页连答案正文一起搜。
- **学习计划**：把几个包串成一条路径，顶部一键切包、不重载页面；计划可以新建、编辑、导入、删除。
- **跨包引用**：条目之间可以指到别的学习包，点一下就跳过去，跳完能一键回计划；目标包没装会显示为不可点。
- 深色 / 浅色两套主题。

## 用自己的内容

学习包就是一个 JSON 文件，不用重新装 App：

1. 把 `.json` 发到手机（微信、网盘、数据线都行）；
2. 用「其他应用打开」选「题台」，或在 App 里 设置 → 从文件导入；
3. 导入前会先体检结构，不合格的文件不会写入，并列出具体哪条要改。

同一 `id` 的导入包会覆盖内置包，方便改内容而不动 APK。计划文件同理（设置 → 导入计划文件）。

**不想手写**：仓库里的 [`skills/titai-deck-author/`](skills/titai-deck-author/) 是给 AI agent 用的技能，加载后它就能按协议产出可直接导入的知识包与计划，还会自己跑校验器确认全绿。

格式细节见 [协议三册](docs/)（[知识包](docs/deck-protocol.md) / [学习计划](docs/plan-protocol.md) / [总纲](docs/protocol-core.md)）。

## 在电脑上用

同一个 WiFi 下，电脑跑一个 Node 脚本就能当同步服务：

```bash
node tools/sync.js          # 默认 8787 端口
```

- 浏览器开 `http://127.0.0.1:8787` → 控制台：配对码、本机 IP、各包进度
- 浏览器开 `http://127.0.0.1:8787/a/` → 电脑上用同一套界面
- 手机上：设置 → 局域网同步 → 填 `电脑IP:8787` + 4 位配对码，然后拉取 / 推送

合并规则是逐条按时间戳取新，不会互相覆盖。

## 已知限制

- 只有 Android 版；不支持 iOS。
- 局域网同步需要电脑上跑脚本，没有云端、没有公网同步。
- 数据在应用私有目录，卸载 App 会一起删掉（重要进度先推送到电脑）。
