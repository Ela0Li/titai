题台 0.9.2 是一次「只带普适内容」的发布：内置包精简为两个机器学习主题的知识包，外加一个最小样例包；其余主题包不再随仓库分发。

如果你只想拿一个离线刷题 App 用，装上就能开始；自己写内容的话，仓库里的 `skills/titai-deck-author/` 可以让 AI agent 按协议产出可直接导入的知识包与学习计划。

## 装法

1. 下载下面的 `titai-0.9.2.apk`；
2. 手机上打开安装（首次需允许「安装未知来源应用」）；
3. 装完直接开，协议与引擎都在 APK 里，**不需要联网、不需要账号**。

系统要求：Android 8.0（API 26）及以上。从 0.9.x 覆盖安装即可，进度保留。

## 里面有什么

两个知识包、一个学习计划：

| 知识包 | 模块 | 知识点 | 问答 |
|---|---|---|---|
| 机器学习数学基础 | 5 | 32 | 24 |
| 机器学习入门 · 从数据到上线 | 9 | 54 | 60 |

- 「机器学习入门」计划（默认）：数学基础 → 机器学习入门
- 仓库里另有 `decks/demo.json`：最小样例包，给校验器和一致性测试自测用，不随 APK 打包

## 这一版改了什么

- **只保留普适内容**：内置包为机器学习数学基础与机器学习入门；示例包改为 `demo`。
- **修掉一个空包启动问题**：如果上次用的知识包在新版本里已经不存在，App 会回落到当前计划的默认包，而不是停在标题 `undefined`、0 个模块的空页面上。
- 工具的默认测试对象同步到现存的包（一致性测试与搜索测试默认跑 `decks/ml-intro.json`）。
- 删掉一次性迁移脚本 `tools/archive/`（早已被直接编辑 `decks/*.json` 取代），仓库更小。

## 功能速览（0.9.x 已有）

- **知识点 / 问答 / 收藏 / 刷题** 四个页签；知识点按等级（P0–P2）与掌握度（模糊 / 会 / 熟练）筛选。
- **模糊搜索**：子串、汉字全拼、首字母（`jcs` → 交叉熵）、子序列、多词 AND，结果按相关度排序并高亮；问答页还能搜答案正文。
- **自由答案结构**：每块自拟小标题，支持 1–3 级嵌套与要点列表；公式用 `$…$` / `$$…$$` 渲染成 MathML。
- **学习计划**：多个包串成一条路径，计划内一键软切包；计划可新建 / 编辑 / 导入 / 删除。
- **跨包引用**：`包id#条目id` 双向跳转，并区分目标包在计划内 / 计划外 / 未安装。
- **知识包导入**：文件选择器、其他应用「打开方式」、电脑局域网下发三条路，导入前先做结构体检。
- **局域网同步**：电脑端 `node tools/sync.js`，同一 WiFi 下按配对码拉取 / 推送进度，逐条按时间戳合并。
- 深色 / 浅色两套主题；进度完全在本地（应用私有目录）。

## 已知限制

- 只支持 Android；iOS 没有。
- 浏览器直开 `index.html` 只有空壳（内容由原生桥从 `assets/decks/*.json` 读）。
- 局域网同步需要电脑上跑 Node 脚本，不支持公网 / 云端。
- 旧版本里装过、这一版已移除的知识包，其进度文件仍留在设备上（不影响使用，重新导入同名包即可接回）。
