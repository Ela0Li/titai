# 题台 0.9.1

搜索从「只认连续原文」换成模糊搜索。

## 现在能这样搜

| 输入 | 命中 |
|---|---|
| `噪声`、`fbm`、`perlin` | 原文片段，不分大小写 / 全半角，无视多余空格 |
| `zaosheng` | 汉字全拼，按音节对齐，越靠后扣分越多 |
| `zs`、`td` | 只打拼音首字母 |
| `nse` | 子序列兜底，能中但分数低 |
| `噪声 fbm` | 空格分词，全部命中才算 |
| `perlin` | 问答页连答案正文一起搜，命中处给「…」片段 |

结果按相关度排序（标题 > 模块名 > 标签 > 知识点正文 > 答案正文），命中字符高亮。知识点页搜索时是一张平铺的相关度列表，每行带所属包、模块和及格线；清空关键词恢复原来的折叠状态。

## 实现上的取舍

- 拼音表是脚本生成的静态表（`assets/pinyin.js`，约 18 KB），不联网、不引第三方库。换字表跑 `node tools/build-pinyin.js`。
- 没有同义词 / 英文别名：搜 `noise` 不会命中「噪声」。那需要一张人工对照表，目前没做。

## 其它

- `/sdcard` 里留给测试的截图会随验收清掉；进度、收藏、计划的存储格式未变，覆盖安装即可。
- 版本号 0.9.1（versionCode 18），协议仍是 v1.7。
