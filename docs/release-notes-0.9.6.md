题台 0.9.6 把两个内置的机器学习知识包按统一体裁重写了一遍，顺带修好了公式渲染里一批「显示成反斜杠源码」的命令，并取消了一个我自己加错的联动（掌握度自动同步）。

内置内容仍是两个包、一个计划（与 0.9.2–0.9.5 相同），覆盖安装即可，进度不受影响。

## 装法

1. 下载下面的 `titai-0.9.6.apk`；
2. 手机上打开安装（首次需允许「安装未知来源应用」）；
3. 装完直接开，协议与引擎都在 APK 里，**不需要联网、不需要账号**。

系统要求：Android 8.0（API 26）及以上。从 0.9.x 覆盖安装即可，进度保留。

## 这一版改了什么

**内容重写**

- **机器学习入门 60 条答案**按体裁重写：概念型走「一句话 / 机制 / 边界」，操作型走「一句话 / 分几步 / 坑」，对比型走「一句话 / 差异 / 怎么选」，不再每条都是「结论 / 机制 / 取舍 / 实战」四段。中位字数 224 → 490，带列表 6% → 23%，带公式 18% → 68%。
- **机器学习数学基础 24 条答案 + 32 条知识点**：答案同样重写（中位 303 → 521，公式覆盖 17% → 100%）；知识点从「名词短语＋冒号」（如「条件数：衡量…」）改成可判分的句子，能在心里默答对错。
- 修掉一处重复题：`q.m1.grad` 与 `q.m4.grad` 原本问的完全一样，现在前者讲梯度定义、后者讲「学习率怎么定、条件数为什么让下降变慢」（含 $0<\eta<2/\lambda_{\max}$、$\kappa=100$ 时约 460 步、Armijo 线搜索）。

**行为修正**

- **取消掌握度自动同步**：v1.3 起有个我自己加的设计——同一条问答覆盖的多个知识点共享掌握度，跨包还会往对方的进度文件里写一份。用起来就是「点一个亮一片」，`会 / 熟练` 的区分跟着失真。现在改一个知识点只写它自己，别的知识点、别的包都不动；旧进度不回溯。要整体标记一条问答，用问答自己的掌握度。
- **知识点卡片里点问答不再跳走**：从知识点卡片点开「对应问答」时，问答卡片叠在上面一层，关掉就回到刚才那张知识点卡片，滚动位置不丢。
- **公式渲染补齐**：`\top`（转置，之前 47 处显示成 `\top` 原文）、`\mathbb{R}` / `\mathcal{N}`（现在渲染成 ℝ / 𝒩）、`\xrightarrow{标注}`、`\succeq`、`\ell` 等命令现在都能正常排版。
- **知识点文本不再出现美元符**：知识点行按纯文本渲染，之前写 `$X$` 会把美元符号原样显示出来，这批已改成 `X`、`A+A⊤`、`λ` 这样的 Unicode 写法。
- 协议升到 **v1.10**：§10 从「掌握度同步」改成「掌握度的记账范围」，§7 补了公式命令表与「哪些字段解析公式」；字段与 id 完全不变，老知识包与老进度照旧可用。

## 功能速览（0.9.x 已有）

- **知识点 / 问答 / 收藏 / 刷题** 四个页签；知识点按等级（P0–P2）与掌握度筛选，问答按包、层级、掌握度筛选。
- **模糊搜索**：子串、汉字全拼、首字母（`jcs` → 交叉熵）、子序列、多词 AND，结果按相关度排序并高亮；问答页还能搜答案正文。
- **自由答案结构**：每块自拟小标题，支持 1–3 级嵌套与要点列表；公式用 `$…$` / `$$…$$` 渲染成 MathML。
- **学习计划**：多个包串成一条路径，计划内一键软切包；计划可新建 / 编辑 / 导入 / 删除。
- **跨包引用**：`包id#条目id` 双向跳转，并区分目标包在计划内 / 计划外 / 未安装。
- **知识包导入**：文件选择器、其他应用「打开方式」、电脑局域网下发三条路，导入前先做结构体检。
- **局域网同步**：电脑端 `node tools/sync.js`，同一 WiFi 下按配对码拉取 / 推送进度，逐条按时间戳合并（`checks` / `qm` / `fav` / `quiz` 四张表都合并）。
- 深色 / 浅色两套主题；进度完全在本地（应用私有目录）。

## 已知限制

- 只支持 Android；iOS 没有。
- 浏览器直开 `index.html` 只有空壳（内容由原生桥从 `assets/decks/*.json` 读）。
- 局域网同步需要电脑上跑 Node 脚本，不支持公网 / 云端。
- 公式要 WebView 支持 MathML（Chromium 109+，即 Android 9 以上基本都行）。个别老设备 / 模拟器缺数学字体，会把公式字符显示成方块——这是设备字体问题，不是内容问题。
- 问答的掌握度只用于显示与筛选：不进覆盖率、不进「已掌握」计数，也不影响刷题页「薄弱项」的抽取（那一项仍按覆盖点的知识点分数算）。
- 刷题页答完题选档位仍会写**知识点**的掌握度（那是答题后的自评）。
- 旧版本里装过、后续版本已移除的知识包，其进度文件仍留在设备上（不影响使用，重新导入同名包即可接回）。
