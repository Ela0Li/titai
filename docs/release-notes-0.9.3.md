题台 0.9.3 是一次「把叫法统一」的发布：界面、文档、校验器提示里统一用 **知识包 / 知识点 / 模块 / 问答** 四个词，另外补了一条把学习计划从电脑直接推给手机的深链。

功能与内置内容与 0.9.2 一致，装在原版本上覆盖即可，进度不受影响。

## 装法

1. 下载下面的 `titai-0.9.3.apk`；
2. 手机上打开安装（首次需允许「安装未知来源应用」）；
3. 装完直接开，协议与引擎都在 APK 里，**不需要联网、不需要账号**。

系统要求：Android 8.0（API 26）及以上。从 0.9.x 覆盖安装即可，进度保留。

## 里面有什么

两个知识包、一个学习计划（与 0.9.2 相同）：

| 知识包 | 模块 | 知识点 | 问答 |
|---|---|---|---|
| 机器学习数学基础 | 5 | 32 | 24 |
| 机器学习入门 · 从数据到上线 | 9 | 54 | 60 |

- 「机器学习入门」计划（默认）：数学基础 → 机器学习入门
- 仓库里另有 `decks/demo.json`：最小样例包，给校验器和一致性测试自测用，不随 APK 打包

## 这一版改了什么

- **术语统一**：界面、文档、校验器提示里的「学习包」一律写「知识包」，旧的「自查点」一律写「知识点」；底部导航第一项由「自查」改成「**知识点**」，和协议里 `terms.check` 的默认值对齐。
- **协议正文标题更正**：一直是 `知识包协议 v1.1`，实际协议版本早在 v1.8；标题与修订表已补齐（字段与 id 完全不变，老包不用改）。
- **新增深链 `plan=<url>`**：让手机从电脑取一份计划文件（`tools/serve-dir.js` 起个临时服务即可），校验成员都在本机后入库并切过去——手机端文件选择器不好用时，这是把计划装回去最省事的路。
- **把两个停用的生成脚本标注清楚**：`decks-src/ml-intro/` 与 `tools/build-ml-math.js` 停在 0.7.0，跑一次会把现网内容改回旧结构并丢掉「及格线」提示，现在头部和文档里都写着「已停用，别跑」。

## 功能速览（0.9.x 已有）

- **知识点 / 问答 / 收藏 / 刷题** 四个页签；知识点按等级（P0–P2）与掌握度（模糊 / 会 / 熟练）筛选。
- **模糊搜索**：子串、汉字全拼、首字母（`jcs` → 交叉熵）、子序列、多词 AND，结果按相关度排序并高亮；问答页还能搜答案正文。
- **自由答案结构**：每块自拟小标题，支持 1–3 级嵌套与要点列表；公式用 `$…$` / `$$…$$` 渲染成 MathML。
- **学习计划**：多个包串成一条路径，计划内一键软切包；计划可新建 / 编辑 / 导入 / 删除。
- **跨包引用**：`包id#条目id` 双向跳转，并区分目标包在计划内 / 计划外 / 未安装。
- **知识包导入**：文件选择器、其他应用「打开方式」、电脑局域网下发三条路，导入前先做结构体检。
- **局域网同步**：电脑端 `node tools/sync.js`，同一 WiFi 下按配对码拉取 / 推送进度，逐条按时间戳合并。
- 深色 / 浅色两套主题；进度完全在本地（应用私有目录）。

## 已知限制

- 只支持 Android；iOS 没有。
- 浏览器直开 `index.html` 只有空壳（内容由原生桥从 `assets/decks/*.json` 读）。
- 局域网同步需要电脑上跑 Node 脚本，不支持公网 / 云端。
- 旧版本里装过、后续版本已移除的知识包，其进度文件仍留在设备上（不影响使用，重新导入同名包即可接回）。
