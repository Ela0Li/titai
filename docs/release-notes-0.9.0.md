题台 0.9.0 是第一个对外发布版本：一个纯离线的安卓刷题 / 自查 App，内容（知识包）与程序分离，进度按时间戳合并，手机和电脑可以各自用、也可以局域网同步。

## 装法

1. 下载下面的 `titai-0.9.0.apk`；
2. 手机上打开安装（首次需允许「安装未知来源应用」）；
3. 装完直接开，协议与引擎都在 APK 里，**不需要联网、不需要账号**。

系统要求：Android 8.0（API 26）及以上。

## 里面有什么

五个知识包、两个学习计划：

| 知识包 | 模块 | 知识点 | 问答 |
|---|---|---|---|
| 计算机基础 · 面试复习 | 6 | 62 | 47 |
| 计算机图形学 · 图形与渲染 | 3 | 42 | 39 |
| UE5 PCG · 程序化生成 | 9 | 90 | 92 |
| 机器学习数学基础 | 5 | 32 | 24 |
| 机器学习入门 · 从数据到上线 | 9 | 54 | 60 |

- 计划一「机器学习入门」（默认）：数学基础 → 机器学习入门
- 计划二「计算机基础 · 图形学 · UE5 PCG」：三个包按顺序串起来

## 这一版能做什么

- **知识点 / 问答 / 收藏 / 刷题** 四个页签；知识点按等级（P0–P2）与掌握度（模糊 / 会 / 熟练）筛选。
- **答案结构自由**：每块可以自定义小标题，支持 1–3 级嵌套与要点列表；公式用 `$…$` / `$$…$$`，渲染成 MathML。
- **学习计划**：多包串成一条路径，计划内一键软切包（不重载页面）；计划可新建 / 编辑 / 导入 / 删除。
- **跨包引用**：`包id#条目id` 双向跳转，并区分目标包在计划内 / 计划外 / 未安装三种状态。
- **知识包导入**：文件选择器、其他应用「打开方式」、电脑局域网下发三条路，导入前先做结构体检。
- **局域网同步**：电脑端 `node tools/sync.js`，同一 WiFi 下按配对码拉取 / 推送进度，逐条按时间戳合并。
- 深色 / 浅色两套主题；进度完全在本地（应用私有目录）。

## 已知限制

- 只支持 Android；iOS 没有。
- 浏览器直开 `index.html` 只有空壳（内容由原生桥从 `assets/decks/*.json` 读）。
- 局域网同步需要电脑上跑 Node 脚本，不支持公网 / 云端。
- 公式排版依赖系统 WebView 的数学字体，少数老旧机型可能缺字。
- 模拟器（Chromium 110）上公式会显示成方框，是镜像缺字体，不是 App 的问题。

## 协议与许可

协议 v1.7（三册：总纲 / 知识包 / 学习计划），第三方可以照协议写自己的知识包并通过 `tools/validate-deck.js` + `tools/conformance.js` 自检。代码以 MIT 许可发布，知识包内容可自由改写。
