题台 0.9.5 让**问答也有了自己的掌握度**，顺手补上刷题页的收藏按钮，并把问答卡片里的「覆盖点」做成真正的叠卡片跳转。

内置内容与 0.9.4 一致，覆盖安装即可，进度不受影响。

## 装法

1. 下载下面的 `titai-0.9.5.apk`；
2. 手机上打开安装（首次需允许「安装未知来源应用」）；
3. 装完直接开，协议与引擎都在 APK 里，**不需要联网、不需要账号**。

系统要求：Android 8.0（API 26）及以上。从 0.9.x 覆盖安装即可，进度保留。

## 里面有什么

两个知识包、一个学习计划（与 0.9.2–0.9.4 相同）：

| 知识包 | 模块 | 知识点 | 问答 |
|---|---|---|---|
| 机器学习数学基础 | 5 | 32 | 24 |
| 机器学习入门 · 从数据到上线 | 9 | 54 | 60 |

- 「机器学习入门」计划（默认）：数学基础 → 机器学习入门
- 仓库里另有 `decks/demo.json`：最小样例包，给校验器和一致性测试自测用，不随 APK 打包

## 这一版改了什么

- **问答自己的掌握度**：以前掌握度只记在知识点上，问答只能借「覆盖点」间接体现。现在每条问答另存一份自评（进度文件里新增 `qm` 表，键是问答 id），和知识点的分数**各记各的、互不加权**。改法跟知识点一样：只能在问答卡片里改，三档单选、只亮当前档、再点一次取消；列表、收藏、刷题页都只显示三个圆点（1 个=模糊、2 个=会、3 个=熟练，黄 / 蓝 / 绿）。
- **问答页按掌握度筛选**：除「按知识包」「按层级」两行外，多了一行「问答掌握度」（全部 / 未学 / 模糊 / 会 / 熟练），可以和前两行叠着用。
- **刷题页加「☆ 收藏这题」**：抽到想反复看的题，直接在卡片下面收藏，不用再绕去问答页翻。
- **「覆盖点」点开是叠卡片**：在问答卡片里点覆盖点，对应知识点卡片会**盖在问答卡片上面**，问答卡片不关、原样留在后面（只被遮罩压暗，不缩小、不透明），关掉知识点卡片就回到原来那一屏、滚动位置不变。跨包引用仍按老规矩走跨包跳转。
- **协议 v1.9**：只动进度层（多了 `qm` 一张表，见 `docs/protocol-core.md` §10.4），内容层字段与 id 完全没变，老知识包、老进度文件照旧可用。

## 功能速览（0.9.x 已有）

- **知识点 / 问答 / 收藏 / 刷题** 四个页签；知识点按等级（P0–P2）与掌握度筛选，问答按包、层级、掌握度筛选。
- **模糊搜索**：子串、汉字全拼、首字母（`jcs` → 交叉熵）、子序列、多词 AND，结果按相关度排序并高亮；问答页还能搜答案正文。
- **自由答案结构**：每块自拟小标题，支持 1–3 级嵌套与要点列表；公式用 `$…$` / `$$…$$` 渲染成 MathML。
- **学习计划**：多个包串成一条路径，计划内一键软切包；计划可新建 / 编辑 / 导入 / 删除。
- **跨包引用**：`包id#条目id` 双向跳转，并区分目标包在计划内 / 计划外 / 未安装。
- **知识包导入**：文件选择器、其他应用「打开方式」、电脑局域网下发三条路，导入前先做结构体检。
- **局域网同步**：电脑端 `node tools/sync.js`，同一 WiFi 下按配对码拉取 / 推送进度，逐条按时间戳合并（`checks` / `qm` / `fav` / `quiz` 四张表都合并）。
- 深色 / 浅色两套主题；进度完全在本地（应用私有目录）。

## 已知限制

- 只支持 Android；iOS 没有。
- 浏览器直开 `index.html` 只有空壳（内容由原生桥从 `assets/decks/*.json` 读）。
- 局域网同步需要电脑上跑 Node 脚本，不支持公网 / 云端。
- 问答的掌握度目前只用于显示与筛选：它不进覆盖率、不进「已掌握」计数，也不影响刷题页「薄弱项」的抽取（那一项仍按覆盖点的知识点分数算）。
- 刷题页答完题选档位仍会写**知识点**的掌握度（那是答题后的自评）。
- 旧版本里装过、后续版本已移除的知识包，其进度文件仍留在设备上（不影响使用，重新导入同名包即可接回）。
